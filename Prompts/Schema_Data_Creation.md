# SCHEMA and DATA Creation

Introduction: This is set of projects and resources used to create schema and initial required data including lookup data and master data of more than 15 restaurants and menus. Resources can be prompts used for various purpose.

Purpose: The set of project is required to create data creation scripts, lookup data creation scripts, master data for restaurants and their menu including required details. An attempt to create the data insertion sql programmatically has been done. It will have multiple services and projects.

Folder Structure: There are mainly three folders

- Prompts: All prompts required to achieve the purpose are in MD format in this folder.
- SQL: There are two subfolder into it
  - SCHEMA: This folder has all files required to create schema, lookup tables and automation scripts
  - DATA: This folder has insert data script for each restaurant and automation script.
